# BYUI Support Chat Widget 💬

This is a lightweight and responsive floating chat widget designed for the **FTC Chatbot**. The script dynamically injects a modern user interface into any website, enabling direct communication via a Google Apps Script backend.

## ✨ Features

* **Floating Interface:** A bubble button featuring a **Neon Pulse** animation to attract user attention.
* **Resizable Window:** Users can manually adjust the chat dimensions for a better experience.
* **Maximize Mode:** A dedicated toggle to expand the chat to near full-screen (90vw/90vh).
* **Fluid Animations:** Smooth fade-in and scale transitions powered by pure CSS.
* **Zero Dependencies:** Built entirely with **Vanilla JavaScript**; no need for jQuery or external libraries.
* **Easy Configuration:** A centralized `CONFIG` object allows for quick adjustments to URLs, dimensions, and z-index.

---

## 🚀 Tech Stack

* **JavaScript (ES6+):** Widget logic, DOM manipulation, and event handling.
* **CSS-in-JS:** Styles are injected dynamically to keep the implementation contained in a single file.
* **Google Apps Script:** Acts as the backend to process chatbot logic via an `iframe`.
